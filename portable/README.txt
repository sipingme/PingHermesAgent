PingHermesAgent 便携版
======================

1. 双击 Start PingHermesAgent.command（Mac）或 Start PingHermesAgent.bat（Windows）启动。
2. 所有配置、会话与 Agent 数据保存在本文件夹的 data/ 目录中。
3. 请勿在运行中拔出 U 盘。
4. 建议使用 USB 3.0 及以上 U 盘，格式 exFAT。

离线包需包含预装 Python 后端（data/hermes/）；仅 UI 时请在有网电脑按 docs/PREPARE-USB.md 制作完整包。

首次在 Mac 上若无法打开：
  右键 PingHermesAgent.app 或启动脚本 → 打开

完整 U 盘模板见 sibling 仓库 PingHermesAgentPortable/
